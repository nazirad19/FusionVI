# FusionVI

FusionVI tests a small, interpretable change to the totalVI encoder for paired
single-cell RNA and surface-protein measurements. It asks:

> When immune stimulation produces RNA/protein disagreement, can a per-cell
> modality gate recover pharmacodynamic response states and activation markers
> in unseen donors more reliably than standard totalVI?

The study uses the Lawlor et al. PBMC CITE-seq experiment: 16,382 cells from 10
paired donors under baseline, LPS, or anti-CD3/CD28 stimulation, with 39 ADTs.

## Method

Standard totalVI concatenates thousands of RNA features and tens of proteins in
one encoder. FusionVI replaces only that encoder with two equal-width branches:

1. an RNA branch;
2. a protein branch; and
3. a learned scalar gate for every cell that fuses the two representations.

The totalVI decoder, RNA/protein likelihoods, latent size, training objective,
preprocessing, random seed, and donor splits remain fixed. This makes the test
an encoder ablation rather than a new generative model.

CD25, CD69, and HLA-DR are hidden from all encoder inputs. Their reconstruction
therefore tests cross-modal biological recovery instead of circularly scoring
proteins the model already saw. CD80 was measured by external flow cytometry in
the paper but is absent from the released 39-ADT matrix, so it is not claimed as
an input-panel endpoint here.

## Evaluation design

- **10-fold leave-one-donor-out validation**: each donor is the test set once.
- **Direct responses**: anti-CD3/CD28 T cells and LPS monocytes.
- **Harder indirect responses**: NK and B cells under anti-CD3/CD28.
- **Held-out markers**: CD25/CD69 in T cells and HLA-DR in monocytes.
- **Transparent baselines**: RNA PCA, protein PCA, and equal late-fusion PCA.
- **Statistics**: metrics are computed per held-out donor; model comparisons use
  paired donor-level differences, Wilcoxon tests, bootstrap confidence intervals,
  and Benjamini-Hochberg correction. Cells are never treated as independent
  biological replicates.

## Reproduce

The current project was run with Python 3.12, scvi-tools 1.4.2, PyTorch 2.8.0,
and a CUDA GPU. From PowerShell:

```powershell
python -m venv .venv
.\.venv\Scripts\python -m pip install -r requirements.txt
$python = '.\.venv\Scripts\python.exe'
& $python src\download_data.py
& $python src\prepare_data.py
.\run_cv.ps1
& $python src\classical_baselines.py
& $python src\evaluate.py
```

The PowerShell runners prefer a local `.venv` and fall back to the shared
workspace environment used for this execution.

## Repository layout

- `config/default.yaml` — fixed experiment configuration.
- `src/download_data.py` — HCA downloads with expected checksums.
- `src/prepare_data.py` — annotation matching, raw-count preservation, and
  lane-aware highly-variable-gene selection.
- `src/fusion_encoder.py` — masked totalVI and dual-branch gated encoders.
- `src/train_fold.py` — one deterministic donor-held-out fold.
- `src/classical_baselines.py` — donor-held-out PCA baselines.
- `src/evaluate.py` — biological metrics, paired statistics, and figures.
- `results/` — compact result tables and figures after execution.

Large raw matrices, processed AnnData, model weights, and per-cell fold files
are intentionally ignored by Git and regenerated by the pipeline.

## Interpretation

This is an exploratory pharmacodynamic biomarker study at one 24-hour timepoint,
not a dose-response model. A positive result means the gated encoder better
preserves a stimulation-associated signal in new donors. It does not establish
clinical utility or causality. A negative result is also informative: it would
show that totalVI's existing joint encoder is already sufficient for these
readouts, or that the dataset lacks enough evidence to justify adaptive fusion.

## Executed result

All 20 planned folds completed at 40 epochs. Standard totalVI already classified
the four stimulation contrasts with mean held-out-donor ROC AUCs of 0.995 to
1.000, which left little room for an encoder improvement. FusionVI did not
produce a reliable overall gain in held-out protein reconstruction:

- CD25 Spearman correlation was 0.779 for both models.
- CD69 increased from 0.822 to 0.826, with a donor-level adjusted q value of
  0.165.
- HLA-DR increased from 0.404 to 0.421, but donor variability was high and the
  adjusted q value was 0.382.

The learned gate was biologically responsive even though downstream performance
did not improve. Mean protein weight increased from 0.349 at baseline to 0.445
after anti-CD3/CD28 stimulation. In cells with discordant CD69 transcript and
surface protein, protein weight increased by 0.090 on average across donors
(paired Wilcoxon p = 0.00195). This shift did not improve CD69 reconstruction on
that challenge subset. The result supports a specific conclusion: a per-cell
modality gate can learn stimulation context, but adaptive encoder fusion alone
does not overcome the response-recovery ceiling in this dataset.
